# 從 ISO 14064 到 ISO 14083

一個給零基礎讀者的互動式科普網站：從企業熟悉的 ISO 14064-1 溫室氣體盤查出發，一步步理解 ISO 14083 如何量化貨運與客運運輸鏈的排放。

- 純靜態網頁（HTML / CSS / 原生 JS），無建置步驟、無追蹤、無資料庫
- 直接開啟 `index.html` 即可瀏覽；本 repo 以 GitHub Pages 發布
